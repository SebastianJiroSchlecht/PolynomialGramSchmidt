The maintainer reports permission to use the comparison code. The repository does not contain the permission text, so its scope cannot be checked here. In particular, this audit does not establish permission for public GitHub distribution, modifications, or sublicensing under MIT. Before treating these directories as freely redistributable, record the original source/version and the applicable license or an explicit public-redistribution grant from the relevant rights holders, including any downstream helper code. If such a grant is unavailable, the maintainers can distribute instructions/links instead; no files have been removed or relicensed by this audit.

[GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) explains the distinction between public visibility and a license granting reuse/distribution rights. This inventory records missing evidence; it is not a determination that the reported permissions are invalid.
